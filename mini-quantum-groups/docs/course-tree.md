# Course Tree — Mini-Quantum-Groups

## Prerequisite Knowledge Tree

```
Mini-Quantum-Groups
├── mini-object-kernel (Basic types)
├── Algebra
│   ├── Groups, Rings, Fields
│   ├── Modules and Vector Spaces
│   ├── Tensor Products
│   └── Associative Algebras
├── Lie Theory
│   ├── Lie Algebras (sl_2, sl_n)
│   ├── Universal Enveloping Algebras U(g)
│   ├── PBW Theorem
│   └── Representation Theory
├── Category Theory
│   ├── Monoidal Categories
│   ├── Braided Tensor Categories
│   └── Hopf Algebras in Monoidal Categories
├── Combinatorics
│   ├── Binomial Coefficients
│   ├── q-Analogues
│   └── Partitions and Young Tableaux
└── Topology
    ├── Knot Theory (Reidemeister moves, Jones polynomial)
    ├── Braid Groups
    └── 3-Manifold Topology
```

## Downstream Dependencies

```
Mini-Quantum-Groups → Supports:
├── mini-kac-moody-algebras (Affine quantum groups)
├── mini-vertex-algebras (q-deformed vertex algebras)
├── mini-character-theory (q-characters)
├── mini-algebraic-groups (Quantum algebraic groups)
├── mini-category-theory (Braided monoidal categories)
├── mini-combinatorics-discrete-geometry (q-combinatorics)
└── mini-dynamical-ergodic-systems (Quantum integrable systems)
```

## Learning Path
1. Start with q-calculus (q-numbers, q-factorials, q-binomials)
2. Understand U_q(sl_2) generators E, F, K and their relations
3. Study the Hopf algebra structure (Δ, ε, S)
4. Learn about the R-matrix and Yang-Baxter equation
5. Apply to knot theory (Jones polynomial)
6. Explore representations and fusion rules
7. Study advanced topics (roots of unity, crystal bases)
